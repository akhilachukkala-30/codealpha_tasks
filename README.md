# Residential 2BHK Floor Planning

A residential 2BHK floor planning project focused on creating a functional, comfortable, and well-organized home layout. The design includes two bedrooms, a living area, kitchen, dining space, bathrooms, and supporting circulation spaces.

### Features

* Functional 2BHK residential layout
* Efficient space planning and room placement
* Proper circulation and accessibility
* Natural lighting and ventilation considerations
* Practical furniture arrangement
* Clear architectural floor plan

### Project Objective

The objective is to develop a practical and aesthetically balanced 2BHK residential floor plan that makes effective use of the available space while maintaining comfort and functionality.

### Project Contents

* 2BHK floor plan
* Room layouts and dimensions
* Furniture planning
* Architectural drawings
* Design references and documentation

# 2D Gear Design

A 2D mechanical gear design project focused on creating an accurate and dimensionally detailed gear profile. The design demonstrates fundamental concepts of mechanical drafting, gear geometry, and precision drawing.

### Features

* Accurate 2D gear profile
* Defined pitch circle, root circle, and outer circle
* Proper tooth spacing and geometry
* Dimensioned technical drawing
* Suitable for mechanical design and CAD practice

### Project Objective

The objective of this project is to understand and apply the basic principles of gear geometry and 2D mechanical drafting while creating a precise and well-structured gear design.

### Project Contents

* 2D gear drawing
* Gear dimensions and annotations
* Geometric construction
* CAD design files
* Technical drawing documentation
